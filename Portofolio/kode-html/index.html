Penjelasan Kode yang Saya Pakai dan Pelajari!

HTML

  1. <!DOCTYPE html> : Digunakan untuk memberi tahu browser bahwa dokumen menggunakan HTML5.
  2. <html lang="id"> : Tag paling luar yang membungkus seluruh isi. HTML.
  3. lang="id" : Menentukan bahwa bahasa utama halaman adalah bahasa Indonesia.
  4. <head> : Berisi informasi tentang halaman yang tidak ditampilkan langsung kepada pengguna.
  5. <meta charset="UTF-8"> : Mengatur encoding karakter agar karakter agar huruf, simbol, dan emoji dapat di tampilkan dengan benar.
  6. <meta name="viewport"> : Digunakan agar website responsive di perangkat mobile atau desktop.
  7. <title> : Judul halaman.
  8. <link rel="stylesheet" href="style.css"> : HTML mengambil file CSS agar halaman memiliki tampilan yang beragam.
  9. <body> :berisi seluruh konten yang ditampilkan kepada pengguna, seperti gambar, video, teks, tombol, dll.
  10. <h1> : Heading utama pada halaman.
  11. <h2> : Subheading atau judul bagian.
  12. <h3> : Subjudul dari <h2>.
  13. <h4> : Heading tingkat keempat.
  14. <h5> : Heading tingkat kelima.
  15. <h6> : Heading tingkat keenam.
  16. <img src="#" alt="foto"> : src (lokasi gambar), alt (teks alternatif jika gagal dimuat untuk pembaca layar).
  17. <div> : Container umum untuk mengelompokkan elemen, biasanya di pakai bersama css.
  18. <section> : Digunakan untuk membagi halaman menkadi beberapa bagian.
  19. <header> : Setau saya kode ini berisi logo, nama website, navbar.
  20. <nav> : Tempat menu navigasi.
  21. <footer> : Biasanya berisi copyright, media sosial, dan email.
  22. Class : Digunakan untuk memberi nama pada elemen agar bisa di beri gaya CSS.
  23. id : Berbeda dengan class, id harus unik dalam satu halaman.
  24. <form> : Digunakan untuk menerima input pengguna.
  25. <input> : Input ada banyak tipe yaitu :
    • type="text"
    • type="email
    • type="password"
    • type="number"
    • type="radio"
    • type="chackbox"
    • type="date"
  26. <label> : Memberi nama pada input.
  27. <button> : Tombol untuk aksi tertentu.
  28. <textarea> : Digunakan untuk mengetik pesan panjang.
