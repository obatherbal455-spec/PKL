Prompt AI yang Saya Pakai

Penjelasan Prompt AI

Dalam membuat website portofolio ini, saya menggunakan AI sebagai alat bantu ketika belajar dan mengerjakan proyek. Saya memberi nama AI saya dengan nama "Bro". Jadi saya memberikan prompt atau perintah kepada AI agar membantu menjelaskan kode, mencari solusi jika ada yang error, dan memberikan ide untuk tampilan website.

Prompt yang saya gunakan biasanya berisi penjelasan tentang desain yang saya inginkan, fitur yang ingin dibuat, atau bagian kode yang ingin saya pahami. Dengan prompt yang jelas, Si bro dapat memberikan jawaban yang lebih sesuai dengan kebutuhan saya.

Contoh prompt yang saya gunakan

"Bro, bantu saya membuat website portofolio dengan HTML dan CSS. Jelaskan fungsi setiap kode, bantu jika ada error, dan berikan saran agar tampilannya lebih rapi dan responsif."

Si bro membantu saya memahami materi dan memberikan contoh kode, tetapi saya tetap membaca, mencoba, mengubah, dan menyesuaikan kode tersebut sendiri agar sesuai dengan konsep website yang saya inginkan. Dengan cara ini, saya bisa belajar sambil menyelesaikan proyek portofolio.
