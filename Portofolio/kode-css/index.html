Penjelasan CSS yang saya Pelajari

1. Selector

Selector Digunakan untuk memilih elemen HTML.

2. Color

Color digunakan untuk mengubah warna teks.

3. Background-color

Mengubah warna latar belakang.

4. Background-image

Menambahkan gambar sebagai latar belakang.

5. Background-size

Mengatur ukuran gambar latar belakang.

6. Background-position

Mengatur posisi gambar latar belakang.

7. Background-repeat

Mengatur apakah gambar di ulang atau tidak.

8. Background-attachment

Mengatur apakah background ikut scroll atau tetap diam (fixed).

9. font-family

Mengubah jenis huruf.

10. font-size

Mengatur ukuran teks.

11. font-weight

Mengatur ketebalan teks.

12. font-style

Mengatur gaya huruf.

13. text-align

Mengatur posisi teks (kiri, tengah, kanan).

14. text-decoration

Mengatur dekorasi teks

15. line-height

Mengatur jarak antar baris.

16. width

Mengatur lebar elemen.

17. height

Mengatur tinggi elemen

18. margin

Memberi jarak di luar elemen.

19. padding

Memberi jarak di dalam elemen.

20. border

Memberi garis tepi pada elemen.

21. border-radius

Membuat sudut elemen menjadi melengkung.

22. box-sizing

Mengatur cara browser menghitung ukuran elemen.

23. display

Mengatur cara elemen ditampilkan.

24. position

Mengatur posisi elemen.

25. top

Mengatur jarak dari atas.

26. right

Mengatur jarak dari kanan.

27. bottom

Mengatur jarak dari bawah.

28. left

Mengatur jarak dari kiri.

29. z-index

Menentukan urutan tumpukan elemen.

30. overflow

Mengatur isi yang melebihi ukuran elemen.

31. Flexbox (display: flex)

Mengaktifkan Flexbox.

32. align-items

Mengatur posisi elemen pada sumbu silang (vertikal jika flex-direction: row).

33. flex-direction

Mengatur arah elemen(row atau column).

34. gap

Memberikan jarak antar elemen Flexbox.

35. flex-wrap

Mengizinkan elemen pindah ke baris berikutnya jika ruang tidak cukup.

36. transition

Memberikan efek perubahan yang halus.

37. transform

Mengubah bentuk, ukuran,posisi, atau rotasi elemen.

38. animation

Menjakankan animasi yang di buat dengan @keyframes.

39. opacity

Mengatur tingkat transparansi elemen.

40. box-shadow

Memberikan bayangan pada elemen.

41. text-shadow

Memberikan bayanngan pada teks.

42. cursor

Menngubah bentuk kursor saat di arahkan ke elemen.

43. @media

Memmbuat tampilan menyesuaikan ukuran layar.

44. max-width

Menentukan ukuran maksimum elemen.

45. min-width

Menentukan ukuran minimum elemen.

46. vw

Satuan berdasarkan tinggi layar(viweport width)

47. vh

Satuan berdasarkan tingi layar(viewport height)

48. %

Ukuran bersdasarkan elemen induk.

49. rem

Ukuran berdasarkan ukuran font elemen root.

50. em

Ukuran berdasarkan ukuran font elemen.
